# Как вести Instagram @jumysker_ai (для сессии Claude)

Аккаунт: **@jumysker_ai** (бизнес), приложение Meta «jumysker_ai», вход через Instagram.
Файлы и расписание — в этом репозитории. Публикация — `scripts/publish.py` и `scripts/today.py`, только стандартная библиотека Python.

## 1. Токен

Скрипт берёт токен в таком порядке:
1. переменная окружения `JUMYSKER_INSTAGRAM_TOKEN` (передаётся параметром `access_token`, как в браузере — проверено, работает);
2. файл `~/.claude/channels/jumysker/.env` со строкой `JUMYSKER_INSTAGRAM_TOKEN=…` (права 600);
3. иначе — секрет окружения для `graph.instagram.com` (прокси добавляет `Authorization: Bearer …`).

Никогда не проси прислать токен в чат и не печатай его. Проверка: `python3 scripts/publish.py check` должен вывести `@jumysker_ai · BUSINESS · …`.
Токен живёт 60 дней (выпущен 26.10.2026) — за ~10 дней до конца попроси выпустить новый.

## 2. Первая публикация — только после «да»

1. `python3 scripts/today.py post --date 2026-10-28 --dry-run` — покажи человеку файлы (`content/posts/p01/`) и подпись целиком.
2. Жди явного «да» / «публикуй» в этом чате. Пересказ из другого чата не считается.
3. Опубликуй: `python3 scripts/today.py post --date 2026-10-28`, отправь ссылку одной строкой.
4. Попроси одно постоянное разрешение с рамками, например: «разрешаю публиковать по плану до 22.11».

## 3. Расписание

- Пост или рилс — около 13:00 по Алматы: `python3 scripts/today.py post`.
- Сторис-анонс — через 20 минут: `python3 scripts/today.py story`.
- Задание по расписанию: `CRON_TZ=Asia/Almaty`, будить эту же сессию. Текст: «выполни `git pull` в jumysker-media и `python3 scripts/today.py post`; при успехе напиши ссылку одной строкой; при NO_ITEM_TODAY — молчи; при NOT_READY, NO_FILE или ошибке — напиши человеку, что не так».
- Одна публикация в день. Если вышла ошибка на `media_publish` по таймауту, скрипт сам проверяет последние посты, чтобы не выложить дубль.

## 4. Правила

- Только то, что в `content/schedule.json`. Внеплановые посты, ответы в комментариях и директе, удаление — спрашивать отдельно.
- «Стоп» — сразу остановиться и ничего не публиковать до нового разрешения.
- Вручную в приложении (API не умеет): стикер-ссылка в сторис, музыка Instagram, закрепление постов (закрепить p01–p03), правка подписи.

## 5. Рилсы r3–r8 — собрать накануне даты

Сценарии и демо — в `source/_build/gen/reels_hosted.py`, ведущие — `source/avatar/`. Голос — только ElevenLabs
(ID голосов берутся из reelio-bot или из `JUMYSKER_VOICE_MALE` / `JUMYSKER_VOICE_FEMALE`), Seedance — только картинка, без звука.
Ключи ElevenLabs и BytePlus подставляет прокси окружения. Один клип ведущего ≈ $0,6.

```bash
cd source/_build/gen
python3 make_host.py r3           # голос a/b/c (ElevenLabs) + клип ведущего (Seedance, без звука) в work/
python3 build_reel.py r3          # -> source/reels/r3-erlan.mp4 (1080×1920, субтитры, −14 LUFS)
cd .. && python3 release.py r3    # -> content/reels, сторис-анонс, "ready": true в schedule.json
```

Перед выпуском посмотри кадры и проверь речь; затем `git add content && git commit && git push`.

## 6. Секреты

В репозитории нет и не должно быть токенов, ключей и паролей: он открытый. Токен Instagram — только в настройках
окружения, ключи сервисов подставляет прокси. Перед каждым push проверяй, что в изменениях нет `IGAA…`, `EAA…` и похожих строк.
